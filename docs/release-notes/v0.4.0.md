**Filament is now signed and notarized by Apple.** No more "Open Anyway": download, open, and press Space on any 3MF in Finder.

## Install

**One line (recommended):** open Terminal and run:

```bash
curl -fsSL https://raw.githubusercontent.com/akshaymaloo/filament/main/scripts/install-release.sh | bash
```

**Manual install:**

1. Download **Filament.dmg** below and drag Filament into Applications.
2. Open Filament once to register the Quick Look extensions.
3. Select a `.3mf`, `.stl`, `.obj` or `.ply` file in Finder and press **Space**.

Filament requires macOS 14 or later and runs natively on Apple silicon and Intel Macs.

## What's new

- **Signed with a Developer ID and notarized (#9):** macOS opens Filament without security warnings. The app, both Quick Look extensions and the DMG are signed with hardened runtime, and the notarization ticket is stapled so it also works offline.
- **Project renamed to Filament throughout:** the core library is now `FilamentKit`. Bundle identifiers are unchanged, so upgrading over v0.3.0 keeps your settings and file associations.
- **Smaller app:** test-only code no longer ships inside the app or its extensions.
- **Contributor docs:** new `CONTRIBUTING.md`, `CHANGELOG.md`, `SECURITY.md`, and issue/PR templates.
