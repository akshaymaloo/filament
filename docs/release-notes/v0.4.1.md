**A fresh look and a friendlier first run.** Filament has a new icon, explains why a file can't be previewed instead of showing a blank panel, and walks you through Quick Look setup.

## Install

**One line (recommended):** open Terminal and run:

```bash
curl -fsSL https://raw.githubusercontent.com/akshaymaloo/filament/main/scripts/install-release.sh | bash
```

**Manual install:**

1. Download **Filament.dmg** below and drag Filament into Applications.
2. Open Filament once to register the Quick Look extensions.
3. Select a `.3mf`, `.stl`, `.obj` or `.ply` file in Finder and press **Space**.

Filament requires macOS 14 or later and runs natively on Apple silicon and Intel Macs.

## What's new

- **New app icon:** a modern take on the multicolor filament "f", now on the standard macOS rounded tile.
- **"Couldn't Preview" instead of a blank panel (#7):** Quick Look and the app now say why a file can't be shown (damaged file, no 3D geometry, model too large) and offer **Open in Filament** when the full app can still open it.
- **Welcome and setup window (#21):** shown on first launch and under Help › Quick Look Setup…. It includes a built-in sample model to test Quick Look and a shortcut to the Quick Look extension settings. It can also:
  - **Make Filament the default app:** one click sets it for 3MF, STL, OBJ and PLY, and the window shows which app currently opens each type.
  - **Use Filament for STL/OBJ/PLY on macOS 26+:** copy a single Terminal command to switch Apple's built-in viewer off, with the undo command shown.
- **Multi-plate files open on the first plate with a model** in the app, matching Quick Look.
- **More regression tests:** 215 tests, and CI now requires at least 90% line coverage.
