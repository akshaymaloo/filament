**You no longer need Xcode to install Filament.** From this release on, every version ships as a ready-to-run app for Apple silicon and Intel Macs.

## Install

**One line (recommended):** open Terminal and run:

```bash
curl -fsSL https://raw.githubusercontent.com/akshaymaloo/filament/main/scripts/install-release.sh | bash
```

The script checks the download against its checksum, installs Filament to `~/Applications`, and registers the Quick Look extensions.

**Manual install:**

1. Download **Filament.dmg** below and drag Filament into Applications.
2. Open Filament. macOS blocks the first launch because the app isn't notarized yet (#9). Go to **System Settings › Privacy & Security** and click **Open Anyway**.
3. Opening the app once registers the Quick Look extensions. Then select a `.3mf` in Finder and press **Space**.

Filament requires macOS 14 or later.

## What's new

- **Prebuilt downloads (#5):** a universal, checksummed `Filament.dmg` / `Filament.zip` built by CI for every release.
- **OnShape and ZIP64 3MF files** now open (#1, thanks @bgav).
- **Works alongside Shapr3D and other apps** that register their own `.3mf` type (#2, thanks @JPReding).
- **Optional Filament previews for STL/OBJ/PLY on macOS 26:** `--prefer-filament-stl` replaces Apple's built-in 3D preview for your user account only, and can be undone. The installer no longer shows a false "not registered" warning (#4, thanks @Johnmish).
- **Sturdier with bad or hostile files:** limits on memory use, triangle counts and decompression, safe handling of out-of-range indices and overflowing numbers, protection against component "zip bombs", and cancellation when you move away from a large model mid-load.
- **Clearer thumbnail limits:** very large models (over about 3M triangles) now show Finder's generic icon rather than hanging, and the preview still opens them.
- **Spanish README** (#3, thanks @webbrain-one).

## Under the hood

- The test suite grew from 58 to 172 tests: golden fixtures, offscreen render checks and performance guards. CI now enforces a code-coverage floor (currently 94%).
